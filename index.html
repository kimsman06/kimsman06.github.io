React · Tailwind CSS · shadcn/ui는 네 프로젝트 모두에서, Next.js는 세 곳에서 쓴 공통 코어입니다. 그 위에 제품마다 필요한 스택을 더했습니다. MCSS는 짧은 기간에 맞춰 Server Actions로 백엔드 없이 완주했고, LumoStage는 인증·에셋 저장·AI 작업 큐를 맡을 Express 서버를, D.V.D는 데이터 정합성과 배포 자동화를 위해 NestJS·Docker를 세웠습니다.

중심: 공통 코어 프레임워크 프레임워크 연계 아키텍처 (실선) 프로젝트 앵커 (외곽)
